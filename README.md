# FBWGmodmanager

适用于 **Fireboy & Watergirl** 系列 Steam 版

| key | 作品 |
|---|---|
| `forest` | 1 The Forest Temple |
| `light` | 2 The Light Temple |
| `ice` | 3 The Ice Temple |
| `crystal` | 4 The Crystal Temple |
| `friends` | and Friends |
| `elements` | Elements |
| `fairytales` | Fairy Tales |

三项功能：

| 开关 | 作用 |
|---|---|
| `invincible` | 角色无敌 |
| `timer` | 不超时|
| `gems` | 无视宝石数要求 |

## 使用方法
`FBWGmanager.py`和`FBWGmanager.exe`功能相同，一键安装和卸载（自动启用3项功能），安装后运行游戏，按Ctrl+Shift+F12，选择Console可以单独开关修改项；也可以直接复制`mod.js`里的内容粘贴进控制台安装，关闭游戏后失效。
> **注意：Elements 默认不能打开控制台**，请改用管理器安装。
